# 🔥 FB Emoji Pro - Bộ Emoji Facebook Đầy Đủ & Copy Siêu Tốc

Ứng dụng web hỗ trợ tìm kiếm và copy **toàn bộ emoji Facebook & Unicode (gần 2000 emoji)** phục vụ cho việc viết post bán hàng, content marketing và bài đăng mạng xã hội.

---

## ✨ Tính Năng Nổi Bật

1. **Bộ Emoji Đầy Đủ Nhất (1,997+ Emojis & Ký tự đặc biệt)**:
   - 🔥 **Hot & Bán Hàng**: Các emoji thu hút chú ý, sale, hot, ưu đãi.
   - 🎯 **Gạch Đầu Dòng & Bullets**: Phân cấp mục bài viết ngăn nắp, thoáng mắt.
   - ✦ **Ký Tự Đặc Biệt**: Hoa văn, ngôi sao đen/trắng, mũi tên hoa văn, ký hiệu trang trí.
   - 👉 **Mũi Tên & Kêu Gọi (CTA)**: Điều hướng mắt người đọc, click link, inbox.
   - ✅ **Cam Kết & Uy Tín**: Tích xanh, chứng nhận chất lượng, bảo hành.
   - 📞 **Liên Hệ & Hotline**: SĐT, địa chỉ, bản đồ, shop, ship hàng.
   - ❤️ **Reaction & Cảm Xúc FB**: Like, Tim, Haha, Wow, Buồn, Phẫn nộ.
   - Toàn bộ các danh mục Unicode chuẩn: Mặt cười, Người & Cử chỉ, Động vật, Đồ ăn, Du lịch, Hoạt động, Đồ vật, Biểu tượng, Cờ.

2. **Tìm Kiếm Siêu Tốc Tiếng Việt (Có Dấu & Không Dấu)**:
   - Gõ `lua` hoặc `lửa` hoặc `fire` ➔ `🔥`
   - Gõ `tich` hoặc `tích` hoặc `check` ➔ `✅`
   - Gõ `sao` hoặc `star` ➔ `⭐`
   - Gõ `chi tay` hoặc `tay` ➔ `👉`
   - Gõ `chuong` hoặc `bell` ➔ `🔔`
   - Gõ `tien` hoặc `sale` ➔ `💰`
   - Gõ `dien thoai` hoặc `phone` ➔ `📞`
   - Gõ `xe` hoặc `ship` ➔ `🛵`
   - Gõ `qua` hoặc `gift` ➔ `🎁`
   - Phím tắt tiện lợi: Bấm phím `/` hoặc `⌘K` (Ctrl+K) để nhảy ngay vào ô tìm kiếm, bấm `Esc` để xoá tìm kiếm.

3. **Copy 1-Chạm Siêu Nhanh**:
   - Click vào bất kỳ emoji nào ➔ Tự động copy vào bộ nhớ đệm ngay lập tức.
   - Hiển thị thông báo Toast nổi đẹp mắt và âm thanh phản hồi click (có thể bật/tắt).
   - Nút "Copy Toàn Bộ / Copy Top 30" ở đầu mỗi mục để copy nhanh hàng loạt.

4. **Khay Gom Nhiều Emoji (Emoji Tray)**:
   - Mở khay gom ở góc phải để nhặt nhiều emoji liên tiếp (ví dụ: `👉 🔥 SALE 50% 💥 🛒`).
   - Bấm "Sao Chép Khay" để copy chuỗi emoji đã chọn chỉ với 1 click.

5. **Bộ Chọn Màu Da (Skin Tone)**:
   - Đổi màu da linh hoạt cho tất cả biểu tượng bàn tay và con người (`🟡 🏻 🏼 🏽 🏾 🏿`).

6. **Mục Đã Lưu (Favorites) & Vừa Dùng (Recents)**:
   - Tự động lưu lịch sử các emoji vừa copy.
   - Bấm ngôi sao `☆` để ghim emoji hay dùng lên mục Yêu thích.

7. **Giao Diện Hiện Đại & Dark Mode**:
   - Chuyển đổi giao diện Sáng / Tối tuỳ ý.
   - Tối ưu mượt mà trên cả máy tính và điện thoại.

## 🚀 Hướng Dẫn Cài Đặt & Sử Dụng

### Khởi chạy dự án (Local Dev):
```bash
npm run dev
# hoặc
npm start
```
Trình duyệt sẽ mở tại địa chỉ: `http://localhost:5173/`

### Đóng gói bản chạy tĩnh (Build Production):
```bash
npm run build
```
Thư mục `dist/` sẽ chứa toàn bộ website đã được nén tối ưu (chỉ ~100KB gzip), có thể deploy lên GitHub Pages, Vercel, Netlify hoặc mở trực tiếp.
